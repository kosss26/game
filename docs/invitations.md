# Приглашения и компактное приветствие

Общая иллюстрация `public/share/invitation.jpg` используется в приглашении в игру.
Она не привязана к количеству историй или текущей бесплатной акции.

## Отправка

Кнопки приглашения на главной, в профиле и на странице истории используют
`useInviteFriend`. В Telegram 8.0+ server action `prepareInvitation` проверяет
сессию, берёт Telegram ID из серверного аккаунта и вызывает
`savePreparedInlineMessage`. В результате — иллюстрация, короткий caption и
URL-кнопка в приложение. Клиент вызывает `WebApp.shareMessage`, чтобы игрок сам
выбрал адресата. Приложение не отправляет сообщения друзьям самостоятельно.

Для старого Telegram или ошибки подготовки используется обычный share со ссылкой
`/invite/ref_<id>`. Страница отдаёт OG-метаданные без выполнения JavaScript,
показывает иллюстрацию и кнопку в бот/Mini App с прежним `ref_` параметром.
Личный профиль пригласившего не запрашивается и не публикуется. Невалидные коды
возвращают 404. Страницы помечены noindex/nofollow.

При отмене native picker запасной picker не открывается. Пока готовится карточка,
повторные нажатия блокируются; подготовленная карточка кешируется до истечения
срока. Guest/неавторизованный пользователь не может вызвать подготовку от чужого ID.

## Требования

Для native карточки нужен Telegram 8.0+, настроенные `TELEGRAM_BOT_TOKEN`,
`BOT_USERNAME`, публичный HTTPS `APP_URL`. Telegram должен иметь возможность
загрузить JPEG из `APP_URL/share/invitation.jpg`. Используется существующий
Telegram relay. При его отказе/несовместимости доступна обычная ссылка.
Нативный picker и отображение превью требуют финальной проверки в Telegram после
обновления: локальные тесты используют mock Bot API, сообщений людям не отправляют.

Ссылка CTA сохраняет исходный способ входа: `start=ref_<id>` для бота или
`startapp=ref_<id>` для настроенного Mini App. Правила начисления бонусов не меняются.
Схема БД не меняется. Изображение и thumbnail — примерно 107 и 13 KB.

## Бот

`/start` больше не загружает каталог и не добавляет отдельные кнопки историй.
Сообщение короткое, с одной кнопкой «Открыть истории». Поддержка, /help, /terms и
обработка реферального параметра сохранены. Описания бота также укорочены и
не перечисляют сюжеты, количество которых будет меняться.

## Обновление

После переноса в ветку развёртывания:

```bash
nohup bash -c 'bash /opt/polnoch-stories/deploy/hostkey.sh update && bash /opt/polnoch-stories/deploy/hostkey.sh bot' >/var/lib/polnoch-stories/invitations-update.log 2>&1 </dev/null &
```

```bash
tail -n 50 /var/lib/polnoch-stories/invitations-update.log
```

`bot` применяет короткие описания и меню. Серверные ответы `/start` обновляются
вместе с приложением. Старые сообщения в чатах Telegram не редактируются.

Проверки: typecheck, production build, 113 Jest-тестов; приглашение учитывает
авторизованного игрока, корректно обрабатывает cancel/error/старый клиент,
не запускает Telegram для гостей и не увеличивает приветствие с ростом каталога.

Дополнительно проверена production-страница приглашения на 320/390/430 px: JPEG загружается, ссылка сохраняет ref_, переполнения нет. Ответ для TelegramBot содержит OG-изображение внутри HEAD без JavaScript; неверный код отдаёт 404.
