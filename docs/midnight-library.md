# «Полночь»: главная и профиль

Реализация утверждённого концепта в ветке `design/midnight-library`.

- Тёмные карточки, книжная типографика, знак луны-двери, нижняя навигация.
- Компактное продолжение последней истории ведёт к текущей главе; ожидающая глава — на страницу истории.
- Новая история показана отдельно от продолжения. Названия, главы, ожидание и статистика загружаются из существующих server actions.
- Настройки чтения расположены перед коллекцией. Скорость и таймер сохраняются существующим TelegramProvider; открытая коллекция доступна с клавиатуры.
- Имя и фото берутся из реального профиля Telegram; при отсутствии фото — инициал. Числа из концепта не подставляются в данные игрока.
- Для всех четырёх историй созданы отдельные иллюстрации. `CoverArt` сопоставляет существующие стили `perseids`, `winter`, `forest`, `aurora` изображениям; остальные стили сохраняют SVG-fallback.
- WebP 320/640/1200 px: миниатюры не загружают большие обложки. Изображения используются также на существующих страницах историй. Docker runner копирует `public`.

Исходная ветка развёртывания и настройки Cloudflare не меняются. Чтобы включить новый дизайн на сервере, нужен отдельный шаг развёртывания после просмотра.

## Проверка

`npm run typecheck`, `npm test -- --runInBand`, `npm run build`.
Мобильная проверка в Chromium на 320/390/430 px: загрузка всех изображений, отсутствие горизонтальной прокрутки, переходы в профиль и к текущей главе, сохранение настроек после перезагрузки, раскрытие концовок. Проверка использует отдельную локальную демо-базу, без доступа к данным сервера.
