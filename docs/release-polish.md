# Релизное оформление и сообщения бота

Убрана повторная верхняя шапка главной/профиля: название, аватар-ссылка, значок
студии и дополнительная подпись «Профиль». Основная навигация — нижние вкладки.
Студия доступна администратору внизу профиля.

Страница `/legal` оформлена в стиле приложения, с якорями и отдельными разделами
правил, данных и поддержки. Описаны реальные сохранения, настройки браузера,
Telegram Stars, обращения и резервные копии. Убраны отметка «шаблон»,
неподтверждённые сроки удаления и безусловное обещание возврата за 14 дней.
Это редактура документа и интерфейса; реквизиты владельца должны быть заполнены
реальными сведениями до полноценной юридической публикации.

Публичные реквизиты задаются в `/etc/polnoch-stories/app.env`:
`LEGAL_OPERATOR_NAME`, `SUPPORT_USERNAME` (без @), `SUPPORT_EMAIL`.
Они читаются сервером в рантайме. Страница не выдумывает владельца, если имя не
задано. При отсутствии отдельного контакта ведёт в поддержку самого бота.

## Бот

Общие тексты и команды находятся в `src/lib/telegram/messages.ts`.
Приветствие `/start` короткое, а кнопки историй загружаются из опубликованного
каталога. `/help` объясняет чтение и даёт ссылки на профиль и правила.
`/terms` открывает документ. Описания бота не содержат устаревающего списка
историй; проверены лимиты Telegram.

`/support` и `/paysupport` запрашивают ответ через Telegram ForceReply.
Вариант `/support текст вопроса` также работает. Сообщение с ID и именем
пользователя передаётся получателям `SUPPORT_TELEGRAM_IDS`, либо
`ADMIN_TELEGRAM_IDS`, если отдельные получатели не заданы. Получатель должен
предварительно запустить бота. Переписка не добавляет таблиц в БД.

Оператор отвечает на сообщение «Обращение #…» в чате бота — ответ доставляется
пользователю. Отправлять такие ответы могут только настроенные получатели.
Проверяется, что исходное сообщение создано именно этим ботом. Подтверждение
об отправке обращения показывается только после успешной доставки.
При сбое бот прямо сообщает, что обращение пока не отправлено.

Платёжные уведомления, приглашения и уведомления о главах также отредактированы.
Бизнес-логика покупок и доступа не меняется.

## Развёртывание

Помимо пересборки приложения надо применить новое меню и описания Telegram:

```bash
nohup bash -c 'bash /opt/polnoch-stories/deploy/hostkey.sh update && bash /opt/polnoch-stories/deploy/hostkey.sh bot' >/var/lib/polnoch-stories/release-update.log 2>&1 </dev/null &
```

```bash
tail -n 50 /var/lib/polnoch-stories/release-update.log
```

Обычный `update` пересобирает app/tools и выполняет seed, но не обновляет
Telegram-команды — поэтому `bot` выполняется отдельно после успешного обновления.
Cloudflare Worker, токены и другие приложения не меняются.

## Проверка

`npm run typecheck`, `npm run build`, `npm test -- --modulePathIgnorePatterns='<rootDir>/.next/' --runInBand`.
Тесты бота подменяют доставку сообщений: реальные пользователи и операторы
в проверках сообщений не получают. Проверены лимиты описаний, экранирование,
маршруты `/start` и поддержки, ошибки доставки и ответы только от оператора.
В Chromium проверены главная, профиль и условия на 320/390/430 px.
